# 月卡与星眷累计奖励

[总索引](../../README.md)

状态：未完成

## 功能简介

维护月卡、七日祈愿和星眷累计奖励；商城交易见[商城](commerce.md)。

## 自定义实现

- 激活与续期采用已确认的离线支付，不接真实支付、退款或跨账号服务；有效期按本地时钟推进，回拨不重复领奖。
- 续期保留当日已领状态，上限 179 天；到期不领、漏日不补。月卡经验及小推车各 5% 加成进入实际收益，到期移除；七日祈愿不新增属性。
- 星眷只计本地真实付费订单，包含首购、直购、代金券消费、每日特惠及周期卡，不计代金券购入，旧免费购买不补算；费用、有效期、属性、累计值和领取回执同笔保存。
- 首购未领档位可补领，沿[商城规则](commerce.md#自定义实现)，不能套用月卡漏日规则。
