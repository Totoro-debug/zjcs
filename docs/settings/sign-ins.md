# 主题签到与长期活动入口

[总索引](../README.md)

状态：未完成

## 功能简介

维护主题签到与长期活动任务入口。

## 自定义实现

- 移除服务器活动起止及开服等待，已开放签到长期可领且不过期；保留个人条件、每日一次和有限期奖励表，不自行循环。
- 七日任务按原顺序展示已完成项及首个未完成项，只用真实本地进度，不推测服务端处理中状态；本地目录可提供已确认的便捷入口。
- 签到表 2 使用原通用七日面板及原奖励，独立保存领取天数；这是用户已确认的本地入口。
- 公会战任务仅在有效攻击实际发起时计次，报名、无效目标、已毁据点和次数耗尽不计。联动暂停范围见[离线政策](../features/offline-access.md#暂不开放的联动活动及伙伴)。
