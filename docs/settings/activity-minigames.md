# 成长试炼与活动小游戏

[总索引](../README.md)

状态：未完成

## 功能简介

覆盖成长试炼、宾果、刮卡、节奏、三消、伐木、拼图及其他活动小游戏；地图机关归对应地图。

## 自定义实现

- 个人真实操作和提交结果决定分数、参与及奖励；退出、重复提交和保存失败不增加成绩，不生成联网排名或虚构对手成绩。
- 周年建设按原阶段时长推进，每日最多提交两次；庆典自动完成共享修复并保留个人贡献。
- 问答按本地题池及原权重抽题，保存进度；刮卡先按原奖励权重定奖，中奖格三个相同，其余图案互异，预览排除已用图案。任务批量提交保留余量。
- 节奏游戏支持方向键及 A／D，播放时暂停家园音乐，关闭按当前音量恢复；伐木为五轮、每轮 11 秒，整局才计参与。
- 三消与拼图只推进已接取任务，不追补接取前进度；拼图练习不发奖，一键完成消耗一把破局之匙。共享分数档只在真实挑战首次达标后解锁一次。
- 足球使用本地确定性对手：最近球员射门，蓄力取原曲线长度的 72%，双方各射一次，进球或对方全倒判胜，均未得分为平局；只保存个人胜负平。
- 舞蹈按原题目顺序记录答对数及最长连击，不生成服务器分数、排名或奖励；烧烤以真实本地对局结算，保存失败保留可重试结果。
- 联动暂停范围见[离线政策](../features/offline-access.md#暂不开放的联动活动及伙伴)。
