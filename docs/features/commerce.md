# 商城、代金券与礼包

[总索引](../README.md)

状态：未完成

## 功能简介

维护商城、直购、代金券、周期礼包、首购和兑换；月卡及累计奖励见[月卡](monthly-card.md)。

## 自定义实现

- 金额购买是离线模拟，不接真实支付；代金券扣本地库存。用户可选赛季／礼包目录，各目录限购独立保存，周刷新沿原周一起算。
- 原每日／每周刷新统一采用[06:00 约定](city-and-home/city-and-home.md#全模块刷新时刻)。
- 首购按激活后的对应日领取，超过第三天仍可补领未领档位；月卡未领不补发的规则不适用于首购。
- 用户确认的离线交易不授权改变官方商城布局、展示和交互，未恢复的页面不能作为完整官方还原。
