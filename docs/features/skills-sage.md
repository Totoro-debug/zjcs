## 功能简介

本页维护贤者分支及后续转职的技能、秘法、内置技能和相关子技能／状态的实现详情。职业链为：法师（10） → 贤者（15） → 秘术师（16） → 掌控者（17） → 奥法先知（18） → 真理贤王（22） → 全知贤王（26） → 命运织者（30）。

章节按转职次数划分：初始职业 Rank=1，一阶转职 Rank=2，依次至七阶转职 Rank=8；技能品阶、人物位阶和转职阶级分开记录。每阶清单只列该职业直接新增项，实际装配仍继承全部 PrePro 前置链。当前交付目标仍为初始职业及一阶转职；高阶章节保留已有局部迁移，不扩大已确认的交付范围。
