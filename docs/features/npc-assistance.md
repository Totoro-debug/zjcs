# NPC邀请、站位与战前准备

[总索引](../README.md)

状态：未完成

## 功能简介

维护原 NPC 邀请资格、队伍、站位及战前准备。

## 原始官方实现

邀请窗口沿用原生 prefab、虚拟列表及安全区域适配。来源凭据见 [邀请界面来源清单](../../assets/reference/npc-assistance/team-ui-source-manifest.json)。

## 完整还原部分

邀请文本读取不以官方来源版本决定加载。安全区域恢复官方的矩形尺寸变化触发，窗口挂接完成后会重新适配，避免列表沿用初始化尺寸而偏出视口；不修改官方布局参数。当前静音 Play Mode 已核对实际画面、模拟选择与取消选择、确认与关闭、列表增减及释放；完整邀请玩法和 Windows Player 仍未完成本项验证。

## 自定义实现

- 通用多人战斗队伍为本地主角加所选伙伴，不生成其他玩家；伙伴同步玩家等级与存档阶位，保留原候选资格、排序、人数和次数。剧情显式指定等级／阶位时沿剧情配置。
- 龙之国道路属性门达标后直接开放道路并记本次邀请，不启动战斗或额外发奖；助战使用与道路完成通过可去重回执保持一致。
- 伙伴通话固定 UTC+8，助战次数采用电脑本地时区 06:00 重置，见[刷新约定](../city-and-home/city-and-home.md#全模块刷新时刻)。
- 羁绊及旅行分别见[羁绊冒险](../travel-notes/bond-adventure.md)、[伙伴旅行](../travel-notes/partner-travel.md)，未确认的探索首领等入口不擅自扩展。
