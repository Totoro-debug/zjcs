## 功能简介

本页维护斗士分支及后续转职的技能、秘法、内置技能和相关子技能／状态的实现详情。职业链为：战士（1） → 斗士（6） → 狂战士（7） → 征服者（8） → 破晓狂刃（9） → 瞬狱魔剑（20） → 星陨魔剑（24） → 炼狱魔刃（28）。

章节按官方职业 Rank 划分：初始职业为一阶职业（Rank=1），首次转职为二阶职业（Rank=2），依次至八阶职业（Rank=8）；技能品阶、人物位阶和职业阶级分开记录。每阶清单只列该职业直接新增项，实际装配仍继承全部 PrePro 前置链。当前交付目标仍为初始职业及首次转职；高阶章节保留已有局部迁移，不扩大已确认的交付范围。

#### 已确认的单机差异与对应实现

用户确认秘法 10564 的单机规则：持有的 25029 有效且未被禁用时，每个符合原过滤条件的技能结束累计一次，不要求造成伤害；累计满四次向状态持有者施加一次原 24221，并将计数归零。计数与秘法原培养、祝福和来源随检查点保存。原客户端 `MyFightStatusSkillEnd` 没有服务器实现，旧 `StatusEntClassId` 未指定接收者；持有者绑定与上述累计行为属于已确认的单机适配。

用户确认斗士 10026 每次施放以施法者指向本次选中目标的四向方向选择原 `DirectionEcEntityId`；无目标、同格或无映射使用默认 10780。四向判定沿用原 `Pos2d.LookDirection`，对角等距优先横向。原 `FightSkillData` 只保留方向实体的构造与属性更新，服务器选取实现未提供；此项选择规则属于单机决定。用户进一步要求此能力通用化：按官方显式方向字典统一接入装备施法入口，空字典继续使用原实体；本次范围内 10026 有此字典，其他技能继续使用各自原四向播放配置。此决定不代表未核查高阶技能已验证。
