| <a id="term-0-24082"></a>不屈 | 自身受到的伤害（含真实伤害）降低90%。护盾抵消的伤害不受该效果影响。 |

| <a id="term-0-64"></a>浮空 | 浮空状态下无法触发有攻击动作的反击，格挡时立即解除浮空状态，大体型目标不会被浮空。<br>浮空为即时状态，目标被浮空后，如果没有及时对其造成伤害，则其会在短时间内下落并恢复正常。 |
| <a id="term-0-58"></a>基准概率 | 给目标施加异常状态的基准概率，最终概率会受攻击方的效果命中和受击方的效果抵抗影响。 |

| <a id="term-0-104"></a>效果唯一 | 目标被多次施加该效果时，仅保留最好的效果。 |
| <a id="term-0-80"></a>战斗开始前 | 当战斗双方有多个单位需要在战斗开始前释放技能，按本阶段开始时的速度从高到低依次释放，即速度变化不改变该顺序。<br>当一个角色有多个技能在战斗开始前释放，按照先秘法后战技，同类型按装备位置从上到下依次释放。<br>双方所有单位释放完此类技能后，进入正式战斗回合。 |
| <a id="term-0-8"></a>角色 | 包括玩家角色、伙伴。<br>不包括召唤物、幻兽实体化。 |
| <a id="term-0-108"></a>单段伤害战技 | 造成1次伤害的战技，如斩击、火焰斩。 |
| <a id="term-0-20"></a>补充说明 | 在PVP战斗中，击败召唤物和幻兽的溢出伤害分别衰减至20%和33%。 |
| <a id="term-0-3"></a>真实伤害 | 伤害数值固定，不受状态、亲和等影响。 |
| <a id="term-0-76"></a>异常状态 | 严重影响行为的状态，包括：冰冻、眩晕、定身、霜缚、狂乱。<br>目标被施加异常状态后，下个回合被施加异常状态的概率减半。多个回合连续被施加异常状态，则概率依次衰减。 |
