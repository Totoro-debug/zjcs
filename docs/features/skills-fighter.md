## 功能简介

本页维护斗士分支及后续转职的技能、秘法、内置技能和相关子技能／状态的实现详情。职业链为：战士（1） → 斗士（6） → 狂战士（7） → 征服者（8） → 破晓狂刃（9） → 瞬狱魔剑（20） → 星陨魔剑（24） → 炼狱魔刃（28）。

章节按官方职业 Rank 划分：初始职业为一阶职业（Rank=1），首次转职为二阶职业（Rank=2），依次至八阶职业（Rank=8）；技能品阶、人物位阶和职业阶级分开记录。每阶清单只列该职业直接新增项，实际装配仍继承全部 PrePro 前置链。当前交付目标仍为初始职业及首次转职；高阶章节保留已有局部迁移，不扩大已确认的交付范围。

#### 实现与验证详情

火焰随身 `10061／11200→11201／11202→11203→24210→10860／10861／10862` 的八个原实体已与所选 APK 逐字段核对。保留原技能元素 ID 102、原 `100/skill_14` 动作、自身命中、三条随机子命中、原三格范围及不可驱散的两回合火环。自身附加时刻为原引用延迟 0.15 加单格范围延迟 0.22，即 0.37 秒；其他友方还包含随机父命中的 0.22 秒，合计 0.59 秒。24210 的原近身范围为周围八格，保留附加时、持有者回合、持有者移动及敌方进入范围的原检查标志；原 10860 禁止再触发子技能。原 `StatusTriggerTarget.Creator=3` 明确指定 10860 由最初施法者释放，目标为进入范围的敌方；修正此前将 Source=3 映射成附近敌人的错误，并保留 10061 的培养来源。`scripts/prepare_battle_portable_flame_sources.py` 与[专项来源](../../assets/reference/battle-rules/portable-flame-source-manifest.json)记录十二份原代码、程序集、十八项原生输入／十八项现有 Windows 输出及显式绑定；两个伤害实体缺省的空驱散排除名单只作版本对照，不改历史载荷。

`test_battle_portable_flame.ps1` 已通过 36 组规则流程：四类近身事件分别覆盖自身／友方持环与冷热恢复；完整施法覆盖范围内 0／1／2／3／4／6 名友方、三个随机种子及范围外友方排除，始终给自身与最多三名不同友方附加一次，校验原持续回合、不可驱散、施法者与培养、两类原附加时刻、冷恢复一致和回执重放。每组继续推进至各持有者两回合自然到期，逐边界冷恢复，确认只在该持有者个人回合发出一次结束事件。另以队友持环、敌方仅邻近该队友的完整施法检查原施法者实际扣血来源及冷恢复，友方生命不受影响。原随机父命中的三条子引用各使用一个名额，并共用已选目标排除；其他技能沿用原随机数量。自定义目标 72 例、命中模式、228 次四向装备施法及原地形／移动灼烧来源回归通过。
