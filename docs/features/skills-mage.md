## 特殊词条解释

| 特殊词条 | 解释 |
| --- | --- |
| <a id="term-0-24020"></a>定身【异常状态】 | 无法移动。<br>基础破韧值：30 |
| <a id="term-0-58"></a>基准概率 | 给目标施加异常状态的基准概率，最终概率会受攻击方的效果命中和受击方的效果抵抗影响。 |
| <a id="term-0-64"></a>浮空 | 浮空状态下无法触发有攻击动作的反击，格挡时立即解除浮空状态，大体型目标不会被浮空。<br>浮空为即时状态，目标被浮空后，如果没有及时对其造成伤害，则其会在短时间内下落并恢复正常。 |
| <a id="term-0-15"></a>召唤物 | 召唤物等级与技能等级相同。<br>召唤物不会被施加任何属性增益。<br>召唤物会随召唤者移出战场而立即销毁，如：公会讨伐、讨伐悬赏。 |
| <a id="term-1-3181"></a>石酋 | 在身前召唤1只石酋并立即行动。召唤物按一定比例继承角色属性，在战场中至多存在5回合。（初始冷却完成） |
| <a id="term-0-106"></a>初始冷却完成 | 自身第一回合即可释放本技能，释放后进入冷却。 |
| <a id="term-0-59"></a>治疗 | 释放治疗类战技时，只会对当前血量＜100%的目标进行治疗，治疗量为自身最大生命的一定比例。 |
| <a id="term-0-76"></a>异常状态 | 严重影响行为的状态，包括：冰冻、眩晕、定身、霜缚、狂乱。<br>目标被施加异常状态后，下个回合被施加异常状态的概率减半。多个回合连续被施加异常状态，则概率依次衰减。 |
| <a id="term-0-78"></a>负面效果 | 会产生不利影响的效果，包括：属性降低（如攻击降低）、持续伤害（如侵蚀）、受到伤害增加（如崩破烙印）、炫目、嘲讽等。 |
| <a id="term-0-24215"></a>冰冻【异常状态】 | 不能移动和释放技能，同时也不能触发需角色施法释放的秘法或状态效果。<br>处于冰冻状态时，无法再次被冰冻。<br>基础破韧值：50 |
| <a id="term-0-80"></a>战斗开始前 | 当战斗双方有多个单位需要在战斗开始前释放技能，按本阶段开始时的速度从高到低依次释放，即速度变化不改变该顺序。<br>当一个角色有多个技能在战斗开始前释放，按照先秘法后战技，同类型按装备位置从上到下依次释放。<br>双方所有单位释放完此类技能后，进入正式战斗回合。 |
| <a id="term-0-22"></a>提升最大生命 | 提升最大生命的效果施加或消失时，当前生命比例保持不变。 |
| <a id="term-0-104"></a>效果唯一 | 目标被多次施加该效果时，仅保留最好的效果。 |
| <a id="term-0-8"></a>角色 | 包括玩家角色、伙伴。<br>不包括召唤物、幻兽实体化。 |
| <a id="term-0-12"></a>击退 | 使敌方目标强制后退一定距离，若与其它单位或阻挡物发生碰撞，则发生碰撞的敌方目标受到1次物理真实伤害，伤害量为发生碰撞的敌方目标最大生命的10%，不超过造成击退的角色攻击的60%。 |
| <a id="term-0-11"></a>护盾 | 吸收伤害，受到伤害时优先于生命扣除。<br>当有多个护盾时：<br>1、有回合数限制的护盾优先扣除，无回合数限制的护盾后扣除；<br>2、同类型护盾按施加顺序由先及后依次扣除。 |
| <a id="term-0-9"></a>灼烧 | 灼烧持续3回合，对其上的敌方目标造成1次火元素伤害。<br>伤害触发时机：<br>1、地块刚被附加灼烧时；<br>2、敌方目标移动到灼烧地块上时（移动过程中经过不算）；<br>3、站在灼烧地块上的敌方目标的回合开始时；<br>同回合内，目标受到来自同角色同技能附加的多次灼烧伤害依次衰减35%，最多衰减3次。<br>注：<br>1、同一个地块上，新附加的灼烧会覆盖旧的灼烧；<br>2、灼烧无法附加在水面上；<br>3、灼烧会随附加者移出战场而立即销毁，如：公会讨伐、讨伐悬赏。 |
