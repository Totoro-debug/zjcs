# 古遗物收藏、任务与培养

[总索引](../README.md)

状态：未完成

## 功能简介

家园书桌进入五元素古遗物收藏，每种元素四个槽位。扭蛋获取入口见[古遗物扭蛋](treasure-gacha.md)。

## 原始官方实现

原功能包含遗物收藏、元素槽位、任务计数、套装属性、赐福和培养。遗物只能放入同元素槽位；移动同一件遗物不会复制，替换不清除收藏记录。详细规则以官方客户端与配置为准，来源入口见[来源总表](../../assets/reference/SOURCES.md)。

## 完整还原部分

Unity 当前没有接入书桌收藏、遗物槽位存档、任务属性或培养流程。扭蛋页中的系列收藏弹窗只展示当前系列物品及持有情况，不等于遗物书桌图鉴；该入口记录在[古遗物扭蛋](treasure-gacha.md)。

## 自定义实现

无。
