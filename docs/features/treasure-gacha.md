[总索引](../README.md)

## 功能简介

维护古遗物宝箱、元素扭蛋、女神牌、积分、兑换和抽取演出。

## 自定义实现

- 使用官方已知奖池、权重、数量、过滤及首次规则本地结算，费用、随机、奖励、积分、保底、日计数及历史共同提交。
- 多品质保底在同一抽次到期时，将冲突依次安排在到期前连续抽次兑现；命中某品质后仅该品质未命中数归零。
- 阶位天数按本地解锁后的日历天计算，日界为 Windows 本地午夜，时钟回拨不再次重置。
- 历史同时限制为 180 日和每类 1000 条，超限删最早记录；四类宝箱各计一类，五种元素合并计类。
- 不可重复的整件重复时转对应碎片，蓝／紫／橙／金分别为 20／30／40／60 片。
- 未取得免费修复回调时，已拥有家具或满足原免费修复资格即可访问相关页面；只读判定，不伪写所有权。
