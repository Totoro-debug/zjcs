## 功能简介

本页维护术士分支及后续转职的技能、秘法、内置技能和相关子技能／状态的实现详情。职业链为：法师（10） → 术士（11） → 魔导师（12） → 毁灭者（13） → 黯月魔导（14） → 爆裂魔导（21） → 虚空魔导（25） → 湮灭大师（29）。

章节按官方职业 Rank 划分：初始职业为一阶职业（Rank=1），首次转职为二阶职业（Rank=2），依次至八阶职业（Rank=8）；技能品阶、人物位阶和职业阶级分开记录。每阶清单只列该职业直接新增项，实际装配仍继承全部 PrePro 前置链。当前交付目标仍为初始职业及首次转职；高阶章节保留已有局部迁移，不扩大已确认的交付范围。
