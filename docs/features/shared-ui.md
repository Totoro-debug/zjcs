## 功能简介

维护跨玩法共用的窗口、文字、显示层级和资源复用约定；具体页面交互归所属功能。

## 自定义实现

离线版涉及玩家身份或头像的槽位使用本地角色数据，不生成远端玩家。

## 原生纹理共用

- 仅共用字节与导入设置完全一致的静态纹理，不改变像素、采样或官方表现；原材质、Sprite 和 prefab 的对象身份与字段继续保留。
- 保留动态加载地址、可读或运行时可写纹理、生成器直接使用的模板及其他会话正在修改的素材；不按旧版本目录名删除资源，不合并导入设置不同的副本。
- 共用关系和来源凭据由现有清单维护；重新生成后沿用同一归一化与验证流程，不修改原始输入的预期哈希。隔离工程须沿真实依赖补齐共用目标。
- 事务回滚副本保留至验证完成，检查实际受影响画面后再清理本会话产物。
