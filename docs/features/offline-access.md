# 离线开放条件与单机范围

[总索引](../README.md)

状态：未完成

## 功能简介

统一维护单机开放条件及排除范围；玩法内部阶段和个人资格仍由对应规则决定。

## 自定义实现

- 取消服务器阶位、服务器／注册天数及地图／功能日历开放门槛；保留个人等级、阶位、材料、主线、探索、NPC 资格和玩法内部阶段时长。
- 世界阶段用于内容分档、赛季和历史，独立手动推进，不再充当人物突破、地图或功能的服务器锁；时间流逝不自动推进。
- 真人交易、拍卖、聊天、好友、真人赛事和魔物战争不提供离线替代；公会保留单人范围，助战使用原 NPC，不生成虚构玩家。

### 暂不开放的联动活动及伙伴

用户决定暂停史莱姆、孤独摇滚两个联动及全部关联伙伴：利姆鲁、米莉姆、朱菜、红丸、后藤独、伊地知虹夏、山田凉、喜多郁代。

暂停范围包含活动主页、签到、任务、剧情、小游戏、抽取、兑换、礼包，以及伙伴名册、结识、详情、送礼、档案、对话、旅行和全部助战入口。取消通用日历门槛不构成开放授权，恢复须由用户明确决定；代码和素材保留不代表已开放。
