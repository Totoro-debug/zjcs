## 特殊词条解释

| 特殊词条 | 解释 |
| --- | --- |
| <a id="term-0-64"></a>浮空 | 浮空状态下无法触发有攻击动作的反击，格挡时立即解除浮空状态，大体型目标不会被浮空。<br>浮空为即时状态，目标被浮空后，如果没有及时对其造成伤害，则其会在短时间内下落并恢复正常。 |
| <a id="term-0-122"></a>选目标逻辑的补充说明 | 按以下顺序依次选择：<br>1、优先选择替身；<br>2、优先选择大体型目标；<br>3、优先选择被施加“优先选择为攻击目标”状态的敌方；<br>4、选择技能范围内攻击到最多的目标；<br>5、为本回合释放的最后一个战技时，优先选择远离敌方整体的安全位置，否则优先选择移动距离最短的位置；<br>6、优先选择生命百分比最低的敌方。 |
| <a id="term-0-58"></a>基准概率 | 给目标施加异常状态的基准概率，最终概率会受攻击方的效果命中和受击方的效果抵抗影响。 |
| <a id="term-0-12"></a>击退 | 使敌方目标强制后退一定距离，若与其它单位或阻挡物发生碰撞，则发生碰撞的敌方目标受到1次物理真实伤害，伤害量为发生碰撞的敌方目标最大生命的10%，不超过造成击退的角色攻击的60%。 |
| <a id="term-0-24113"></a>破甲2 | 防御降低30%。<br>不同等级的同名状态同时存在时，仅最高级生效。 |
| <a id="term-0-106"></a>初始冷却完成 | 自身第一回合即可释放本技能，释放后进入冷却。 |
| <a id="term-0-11"></a>护盾 | 吸收伤害，受到伤害时优先于生命扣除。<br>当有多个护盾时：<br>1、有回合数限制的护盾优先扣除，无回合数限制的护盾后扣除；<br>2、同类型护盾按施加顺序由先及后依次扣除。 |
| <a id="term-0-25"></a>生命汲取 | 将对目标生命造成伤害的一定比例用于治疗自身，对护盾造成的伤害则不会触发。 |
| <a id="term-0-80"></a>战斗开始前 | 当战斗双方有多个单位需要在战斗开始前释放技能，按本阶段开始时的速度从高到低依次释放，即速度变化不改变该顺序。<br>当一个角色有多个技能在战斗开始前释放，按照先秘法后战技，同类型按装备位置从上到下依次释放。<br>双方所有单位释放完此类技能后，进入正式战斗回合。 |
| <a id="term-0-104"></a>效果唯一 | 目标被多次施加该效果时，仅保留最好的效果。 |
| <a id="term-0-8"></a>角色 | 包括玩家角色、伙伴。<br>不包括召唤物、幻兽实体化。 |
