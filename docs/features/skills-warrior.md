## 功能简介

本页独立维护初始职业战士（一阶职业，Rank=1）的技能、秘法、内置技能及相关子技能／状态。技能清单、实现详情、单机差异和验证范围在本页集中维护；后续分支为[骑士](skills-knight.md#rank-2)与[斗士](skills-fighter.md#rank-2)，转职后按原 PrePro 链继承本页技能。

本页记录一阶职业（初始职业，Rank=1）；后续职业阶级按官方 Rank 编号。技能品阶和人物位阶另行记录，不与职业阶级混用。

## 原始官方实现

阶级、前置关系及技能归属读取 [`profession_base`／`skill`／`item`](../../unity/Assets/Official/Combat/rules.json)；名称沿用原物品名，职业名按该表关联徽章名核对。实体、被动状态及方向实体读取同目录 [`skill-rules.json`](../../unity/Assets/Official/Combat/skill-rules.json) 与 [`battle-rules.json`](../../unity/Assets/Official/Combat/battle-rules.json)。客户端原码位于 `.tools/source-packages/official-code/`，当前版本补充解码见 `.tools/source-packages/current/884_156692/official-code/`。

当前六职业的 104 项直接技能／物品及 383 个配置引用实体已与所选 884 APK 核对；运行载荷仍保留历史 854 身份，通过明确的版本适配消费差异，技能 UI 继续保留其 871 来源。原码／资源输入身份见[六职业来源凭据](../../assets/reference/battle-rules/first-promotion-source-manifest.json)及各专项链接。

#### 已确认的单机差异与对应实现

用户确认秘法 10544／25023 吸血的单机规则：每次符合原过滤器的成功伤害结算后，以扣盾后的生命伤害、剩余生命裁剪前的数值传入原 SuckHp，过量伤害仍计入，纯护盾吸收为零；保留秘法与伤害技能各自的原属性。在自身格释放原 10520 治疗自己，保留原禁疗／转盾等治疗链；多目标、多段分别结算，遵守原触发白名单，治疗不再触发本吸血。公式、伤害参数与事件绑定已按此接入，当前验证与剩余范围见本阶实现详情。
