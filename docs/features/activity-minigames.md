# 成长试炼与活动小游戏

[总索引](../README.md)

状态：未完成

## 功能简介

活动列表进入成长试炼、宾果抽抽乐、幸运刮刮乐、两套音乐节奏配置（206、221）、四套三消主题（204、208、214、226）、星霜派对伐木（209）及七个拼图主题（200、2076、213、2151、2161、222、2242，其中2161复用界面与题图）。地图中的机关、厨房、躲猫猫和音乐节场景按对应地图维护。

## 原始官方实现

各活动使用自己的官方入口、关卡、计分、道具、奖励与界面；节奏、三消、拼图、伐木、宾果、刮卡、烧烤及其他小游戏不能共用一套近似规则。

### 官方玩法规则

- 成长试炼按原任务、积分档、职业奖励和领奖去重规则运行。
- 宾果使用原抽券、格子候选、连线和轮次奖励；单抽与批量抽取分别结算，轮次奖励须手动领取。刮卡使用三种品质、原权重和 19 种图案，按三同规则结算；保留卡片状态、刮开位置和官方提示／奖励动画。
- 音乐节奏使用官方种子序列和物件队列，按原输入间隔、60 秒计时、连击加分、狂热倍率与失误规则结算；奖励及角色演出由对应活动配置驱动。
- 三消使用原关卡、权重、棋盘重建、匹配／特殊棋子判定、重力连锁与计分规则。步数关按有效交换扣步，限时关按原时钟结束；通关条件和奖励按活动、关卡与任务配置。
- 伐木按原输入、角色动画和树干／障碍状态运行。冰淇淋按 NPC 与配方权重生成订单并校验食材顺序；烧烤按原关卡、配方、食材品质、火候、顾客耐心和挂点容量计分。
- 拼图关卡按活动、关卡和难度前置开放；玩家交换拼块，按实际归位判定通关与奖励。查看参考图时不能操作，练习和一键完成服从原领奖及费用规则。
- 知识问答按原题池权重抽题、洗牌选项、过滤已答题并逐阶段解锁奖励。足球的房间状态、对手操作和胜负提交依赖在线服务。
- 每种小游戏使用各自的官方入口、界面、动画、音效、配置和奖励，不以其他小游戏规则替代。

## 自定义实现

以下离线方案已获确认，当前 Unity 中没有对应小游戏的运行入口或完整流程。

- 周年庆建设按原阶段长度 168／168／167 小时计时；本地每日最多提交两次、每建筑限额沿用原配置，消耗原物资并按进度发奖、防重复领取。庆典阶段自动完成共享修复并保留个人贡献；服务器是否采用相同规则未确认。
- 知识问答以本地题池和原权重抽题，按原规则洗牌并保存答题进度、阶段奖励与领取记录；本地题序不等同线上随机结果。助战与排行不开放。
- 刮卡先按原奖励表与权重确定奖项；三个相同图案中奖，其余格各不相同；另外两档预览从原 19 个图案中选取未用于本卡的图案。该分布是单机补充，其他奖励、权重与动画沿用官方内容。
- 宾果／刮卡任务按实际累计进度在本地批量提交，扣除提交量并保留余量；奖励与上限沿用原表。宾果任务 11601 统计活动激活后的真实消耗，刮卡任务 11900 使用独立扫荡事件。
- 音乐节奏使用本地真实操作生成结果并原子保存；未提交局退出后放弃，重复提交不重复计数，保存失败回滚。键盘左右键与 A／D 对应原按钮；打开时暂停家园背景音乐，关闭后按当前音量恢复，常驻活动入口隐藏剩余时间。
- 伐木按原表 0～4 五组参数各进行一轮，每轮 11 秒，提示按原动画播放。五轮汇总真实得分、个人最高分、参与次数与已接取任务进度；未提交局退出后放弃，不生成排名游戏币。
- 三消保留原小时解锁与前一关条件，本地真实棋盘决定结果；奖励、任务与最高分共同提交，退出和重复提交不计数。万圣节战令只累计已接取任务的真实进度，不另行发放战令奖励。
- 烧烤以本地真实对局取代服务器局号与结果写入。开局保存失败时保留原对局；结算保存失败时保留已完成对局供重试，避免重复发奖或计数。
- 拼图按原小时解锁及难度前置提交真实棋盘结果；练习不发奖。一键完成消耗 1 个道具 325，完成当前题图内符合原规则的未领奖难度并累计对应任务；保存失败回滚并保留可重试状态。
- 共享历史按真实挑战首次达到原分数档解锁该档奖励，每档只领一次；不记录普通关、未提交局或退出局。个人胜负、参与和分数可保留，依赖其他玩家的名次／胜负目标及排行榜入口停用。
- 足球的本地赛制采用确定性对手：最近球员朝球射门，蓄力距离为原曲线归一化长度的 72%；双方各射一次，进球或全队倒下判胜，双方均未得分则平局。局数与胜局数取官方 `MaxStages`／`WinStages`，只保存个人胜负平，不生成在线任务、奖励或排名。物理按原固定步长与碰撞顺序实现，并复用 `Framework.FixedPoint`。
- 舞蹈题目按 `activity_dream_dance_quiz.Id` 顺序播放 168 道；只记录个人答对数和最长连击，不伪造服务器分数、任务或排行。聊天室助战、房间邀请等依赖在线服务的内容不开放。活动年度开放时间映射见[行囊、物品与宝箱](inventory.md)。
