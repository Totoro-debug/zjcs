[总索引](../README.md)

## 功能简介

维护主线、委托、日常／每周和活动任务进度。

## 自定义实现

- 只接受本地明确支持的官方条件，不将未知条件判为满足。委托按原组权重抽组，再从满足条件的组内等概率取任务；重要委托占普通名额，不启用未确认保底。
- 任务、刷新、随机、奖励和领取同笔保存；已移除的真人玩法不生成可领目标。
- 长期玩法永久累计，活动与新纪录从首次打开对应活动建立起点，不补造历史；签到只在实际领取时每日记一次，同日多个主题不重复，登录不计数。
- 小游戏保留真实个人参与和分数任务，停用对手和名次目标；分类统计不同活动，完整提交才计参与，退出、重复或保存失败不计。
- 三消和拼图只推进已接取实例，不追补接取前行为；具体整局及练习规则见[活动小游戏](activity-minigames.md)。
