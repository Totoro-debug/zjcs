# 世界阶段手动推进

[总索引](../README.md)

状态：未完成

## 功能简介

从人物突破页独立查看和推进本地世界阶段，用于原内容分档。赛季按人物 `Rank` 独立映射，不随世界阶段推进。人物突破和世界阶段推进是两个操作，突破不再受服务器阶段锁。

## 原始官方实现

官方世界阶段用于内容分档、赛季及条件判断；原配置和阶段记录保留，单机推进及服务器锁的差异见下文。

### 待迁移的规则与表现

地图交接仍检查原 `StageConLevelComponent`：11／56实体6001要求40级／SubRank5，12／77实体8101要求70级／8，13／82实体8601要求100级／11；区域访问条件为0不代表交接实体免费完成。

人物突破按原下一阶材料。例如4→5仍支付43012×5、40500×40、罗拉20000，不因服务器锁取消而免费。原地图状态、任务、奖励和出口保持真实。

推进弹窗显示原完整章节进度和有效目标，确认携带预期阶段，过期／重复请求拒绝；正在剧情／副本中不推进。

## 自定义实现

`HANDOVER_REQUIRED_RANK` 是既有本地推进政策：三个交接区域分别从世界阶段3／4／5开始计入推进目标，避免用后阶段个人资格阻塞本阶段推进；原地图仍未完成，下一阶段重新计入。

阶段2／3／4原主线区域24／44／64，当前推进要求23／43／63；阶段5～9使用完整84／102／120／138／156。`main_progress.full` 保留原完整数，`deferred` 列推迟项。

用户已取消服务器升阶天数及内容开放锁，本地阶段不再卡人物突破、地图和功能；时间流逝不自动推进。此页替换旧“必须先推进才能突破”的已过期说明。
