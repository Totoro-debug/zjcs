# 邮箱与附件

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 功能简介

邮箱建筑提供本地邮件列表、正文、已读状态、附件领取及删除。

## 当前完成详情

- 已有本地邮件保存、有效期过滤与排序、标记已读、单封和批量附件领取、删除服务及领取回执。
- 已接入邮件列表与正文窗口、全部已读、批量领取和删除已读操作。列表日期和正文时间仍置空，详情页未接入单封删除。当前的邮件新增调用来自验证流程，实际玩法投递尚未接入。
- 待核实附件图标与数量、部分附件领取、到期与重复领取保护、返回列表和冷读恢复的完整操作，以及 Windows Player 表现。

## 自定义实现

新档不虚构邮件。仅处理真实本地玩法产生或已保存的邮件，不生成模拟服务器补偿、活动和社交邮件。
