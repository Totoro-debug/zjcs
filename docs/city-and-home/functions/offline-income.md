# 离线产出、领取与时间结晶

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 功能简介

维护设施收益的本地时间累计、容量、预览、领取、加成和时间结晶加速。设施页面见[床](../buildings/bed.md)和[小推车](../buildings/cart.md)，果树独立结算见[果树](../buildings/fruit-tree.md)。

## 当前完成详情

- 已接入收益选择、产量与容量公式、普通领取、免费与道具快速挂机、加成读取和领取回执。加速请求可保存并在中断后恢复处理。
- 已接入家园收益向角色库存转入、床产出、奖励队列和快速挂机进度窗口。床普通领取已核实原生按钮、单次回执、经验转入、展示不重复发放及存档重开，Windows Player 验证与发布尚未完成；完整跨存档事务链仍需结合失败恢复核实。
- 床免费快速挂机已核实原生动画自然结束、HUD 恢复、结束后发放经验，以及每日次数与经验的存档重开；Windows Player 验证与发布尚未完成。
- 加成详情复用同一原生弹窗与本地活动账本，按原分组显示来源、比例和剩余时间，保留单组与多组背景、原生滚动和点击外部关闭；已核实实际界面及存档重开，Windows Player 验证与发布尚未完成，不为展示创建活动记录。
- 共用活动时间分段已接入果树；床、小推车已有活动快照、分段产量投影及活动账本核心，保留普通挂机公式的参数顺序、原始浮点比例和分别取整。账本核心在满容量时停止累计，容量加成到期保留已产收益与小数。
- 普通收益已接入存档事务，已核实预览无写入、领取失败回滚、活动替换、属性变化、道具加速保留原收益和冷读恢复。
- 主城运行入口和原生床窗口已接入同一收益投影，沿用原生数量、容量及进度控件。活动变更与起止边界更新数量、容量和加成说明，并与结算共用防回拨时钟；床的活动分段领取、冷读恢复、容量到期及详情入口刷新已通过独立 Unity 实际交互和画面验证，Windows Player 验证与发布尚未完成。
- 待核实长时间离线、满容量、加速超容量、加成到期、时钟回拨、领取失败与中断后的冷读恢复，以及 Windows Player 中的完整交互。

## 自定义实现

- 普通领取使用客户端未结算预览结果。时间结晶加速的普通产物留在设施内，可超容量，须手动领取。
- 本地收益按时间累计，负时间差归零，领取失败回滚。活动加成只来自实际活动记录，新档不虚构加成；床、小推车和果树按活动生效与到期边界分段结算，仅生效时段享受加成。
- 日／周额度沿[全模块刷新时刻](../../common/refresh-time.md)，通用存档事务与时间回拨约定见[本地存档](../../settings/settings-and-save.md)。
