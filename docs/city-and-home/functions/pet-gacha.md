# 幻兽结缘与兑换

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 功能简介

维护结缘果树进入的幻兽结缘、兑换及抽取演出；设施本体见[命运之树·结缘](../buildings/pet-tree.md)，养成见[幻兽](../../character/pets.md)。

官方积分馈赠随结缘累计积分，达到各档门槛可领取对应奖励；积分条显示当前档奖励和扣除上一档门槛后的进度，未达成时停用领取入口并保留详情入口。详情按钮打开馈赠说明，支持批量领取的类型还须满足功能解锁条件。

官方百抽前显示可勾选的确认窗口，每次打开重置为未勾选。只有确认时才记录“今日不再提示”，取消不保存；后续提示按该次确认时刻和每日刷新判定。

## 自定义实现

- 按已知类别与候选权重本地抽样，使用可核实的原保底；动态权重缺少服务器公式时不臆造，不声称随机序列与线上一致。
- 积分馈赠保留官方单领与同组批领分支；网络领奖请求改为本地存档事务，同组批领将奖励与领取记录一次提交。已有逐项领取记录按连续已领档位投影到原生积分条，不因较后档位已领取而跳过前方未领档位。
- 百抽“今日不再提示”按确认时的本地刷新日保存；同日和时间回拨到此前日期时保持免提示，下一刷新日恢复确认。勾选只在确认时提交，取消不保存；该选择独立于抽取事务，每日次数仍沿用自身的回拨保护。确认框生命周期共用[建筑窗口宿主](../buildings/management.md)。
- 重复幻兽按品质转碎片：史诗 30、传说 60；同批逐抽即时更新持有状态，再判断下一抽重复。
- 刷新沿[06:00 约定](../../common/refresh-time.md)。价格按钮隐藏黑底的用户调整与[祈愿](wishes.md)一致，其余保持原表现。
