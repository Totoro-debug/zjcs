# 建筑修复、解锁、升级与装潢

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 功能简介

维护各建筑共用的未修复、可修复、已修复状态，产出项解锁与升级，以及家具、主题和环境装潢。床、小推车、果树等设施的专属行为见[建筑导航](../city-and-home.md#建筑)。

- 已连接官方修复与产出条件，本地保存家具所有权、产出项解锁和等级、装潢选择。修复和升级已接入费用检查及失败处理。
- 已接入原修复窗口、升级相关窗口、修复特效和部分家具解锁剧情。装潢页面可检查资格、预览与穿戴，并更新场景图层。

- 共用宿主按官方区分存档数据更新与切换家园通知：条件、收益和外观仍随数据刷新，原生修复协程按预制体时序切换模型并结束特效。独立主城的实际演出验证范围分别记录在各建筑页。

- 原始外观控制器与 Spine SDK 之间使用共用适配层，保留骨骼、皮肤、网格、动画和材质执行；本地资源目录承接原始纹理请求及生命周期。各建筑和外观预制体须分别绑定并验证。

## 原始描述与完成口径

各建筑页的官方物品说明来自实际取得的所选官方中文表；原文缺失时明确记为未提供，文案与设施作用不符时保留原文并解释，不自行补造。配置、条件引用闭包、控制器与中文表的来源凭据见[建筑原始功能来源](../../../assets/reference/home-buildings/source-manifest.json)，可通过提取工具重新核验；该参考数据不替换已迁移的运行规则。

“部分完成”只说明已有实现；“已完成”须完成原生场景和界面、个人资格与解锁剧情、专属交互与动画、本地状态与冷读恢复，以及实际 Windows Player 验证。独立功能验证完成后可单独标记，不能由资源已接入推导建筑已完成。共享规则和已确认方案只在所属公共或功能页维护，各建筑引用同一所有者。
