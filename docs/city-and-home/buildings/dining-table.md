# 餐桌电话

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“餐桌上放着一个电话，似乎可以与伙伴进行通讯。”

设施修复后提供伙伴通讯入口，包含解锁剧情；伙伴的结识、通话条件、分支和奖励由伙伴模块管理。

## 完成概要

已迁移餐桌原生模型（默认造型及全部主题皮肤）、状态机切换（未解锁 / 可修复 / 已修复）、解锁剧情 `UnlockCommunication`（含建筑与修复按钮遮罩引导）以及餐桌点击 / 冒泡提示到原生伙伴面板与伙伴通话界面的完整入口，独立 Unity 工程运行时与视觉验证通过。Windows 交付实包验证将在主城与全建筑集成后完成，届时标记为`已完成`。

## 单机适配实现

- 通话、历史、奖励、头像与日界的单机规则及红点链路复用[伙伴](../functions/partners.md)服务与存档，`NpcDialoguePanelRewardItemContent` 补全全部 86 种通话奖励 `ItemIcon` 及 `GotGrayObj` 已领附件资源目录；奖励资源与主城素材分别保留原始绑定，避免导入时引用冲突。
- 共用解锁条件、修复资格、修复弹窗与剧情控制复用[建筑管理](management.md)的原生家具挂载与故事调度链路；受 `FunctionLimit(57)` 约束，未达到开放条件时隐藏通话气泡并阻止进入伙伴界面。
