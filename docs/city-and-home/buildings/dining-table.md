# 餐桌电话

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“餐桌上放着一个电话，似乎可以与伙伴进行通讯。”

设施修复后提供伙伴通讯入口，包含解锁剧情；伙伴的结识、通话条件、分支和奖励由伙伴模块管理。

## 完成概要

已接入共用修复资格、餐桌解锁剧情与伙伴通话相关实现。当前主城建筑点击仍落入设施提示，餐桌到原生伙伴窗口的入口未接通，不能据伙伴模块已有实现标记餐桌完成。

## 单机适配实现

通话、历史、奖励及日界的已确认方案只在[伙伴](../functions/partners.md)维护。餐桌应复用同一伙伴服务和存档；共用修复见[建筑管理](management.md)。
