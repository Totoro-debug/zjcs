# 储物箱

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“一个形似宝箱的箱子，是冒险者的储物箱。”

官方点击储物箱打开行囊；它不建立独立于角色行囊的第二份库存。

官方家具配置将其设为默认家具，没有解锁条件、修复费用或解锁剧情，不另造修复流程。

## 完成概要

已接通默认家具状态、主城场景点击、角色行囊打开与原始关闭按钮返回；独立 Unity 工程使用隔离角色库存验证了关闭主城后重新进入仍读取同一物品及数量。入口、返回与共享库存冷读链路已完成。

已修复阻止行囊初始化的料理目录校验和排序控件冲突，行囊复用共用安全区组件并显示原物品数量。建筑原生层级、武器架、分类状态与动画表现及完整 Windows Player 流程仍待完成；入口验证不代表整座建筑完成。

## 单机适配实现

复用角色的[行囊](../../character/inventory.md)及其事务，不复制物品。修复与装潢见[建筑管理](management.md)。
