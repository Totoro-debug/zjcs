# 储物箱

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“一个形似宝箱的箱子，是冒险者的储物箱。”

官方点击储物箱打开行囊；它不建立独立于角色行囊的第二份库存。

## 完成概要

主城已连接储物箱到行囊，共用场景与建筑状态已有实现。建筑点击、行囊交互、窗口返回和冷读恢复的完整 Windows Player 流程仍待验证。

## 单机适配实现

复用角色的[行囊](../../character/inventory.md)及其事务，不复制物品。修复与装潢见[建筑管理](management.md)。
