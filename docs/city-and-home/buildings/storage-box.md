# 储物箱

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“一个形似宝箱的箱子，是冒险者的储物箱。”

官方点击储物箱打开行囊；它不建立独立于角色行囊的第二份库存。

官方家具配置将其设为默认家具，没有解锁条件、修复费用或解锁剧情，不另造修复流程。

## 完成概要

已接通默认家具状态、主城场景点击、角色行囊打开与原始关闭按钮返回；独立 Unity 工程使用隔离角色库存验证了关闭主城后重新进入仍读取同一物品及数量。入口、返回与共享库存冷读链路已完成。

原始储物箱点击控制器已迁移，沿用[共用家具控制器](management.md#当前完成详情)打开角色行囊；其组件验证已通过，原生建筑接入仍待完成。

武器架的原生架体、主副手槽位、家园显示模式和主手显隐事件已恢复并完成独立 Unity 组件验证。原始武器选择、变化重载及释放控制器已迁移；这些分支使用组件夹具验证，实际武器纹理、骨骼动画和主城宿主仍待接通。

已修复阻止行囊初始化的料理目录校验和排序控件冲突，行囊复用共用安全区组件并显示原物品数量。建筑剩余原生层级、实际武器表现、分类状态与动画及完整 Windows Player 流程仍待完成；入口与组件验证不代表整座建筑完成。
