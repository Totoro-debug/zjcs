# 储物箱

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“一个形似宝箱的箱子，是冒险者的储物箱。”

官方点击储物箱打开行囊；它不建立独立于角色行囊的第二份库存。

官方家具配置将其设为默认家具，没有解锁条件、修复费用或解锁剧情，不另造修复流程。

武器架展示当前家园主人的武器外观，并按家园视图模式切换显示；主手显隐还响应原始角色动作事件。

## 单机适配实现

复用角色的[行囊](../../character/inventory.md)及其事务，不复制物品。修复与装潢见[建筑管理](management.md)。

武器架读取角色外观，不另存或复制装备。外观控制器通过共用 Spine 适配层使用原始骨骼、皮肤、动画与材质；纹理 GUID 映射到本地资源，沿用原始按需请求和引用释放。
