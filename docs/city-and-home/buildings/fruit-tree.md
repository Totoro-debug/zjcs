# 命运之树：生产与领取

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“结满命运果实的神树，使用命运果实可以在地图中探寻命运。”

生产果树管理果实生产、成熟库存和领取，包含独立修复资格、自动修复条件与解锁引导。[命运之树·结缘](pet-tree.md)单独维护。

## 完成概要

- 已接入生产果树的修复判定、自动修复、本地生产推进、成熟库存、领取和场景状态切换。
- 已有修复效果、果树动画与粒子资源接线，以及引导提示和语音入口；资源接入不等于所有状态的表现均已验证。
- 当前场景以提取的图层、骨架和果实拼装，官方原生树、各装潢及天气变体、果实预制体与控制器尚未完整迁移。原生 `FortuneTree` 红点图还需接通生产修复、结缘、成就、商店与活动等依赖，不能以局部提示替代完整图。
- 商店新商品条件节点已按原始事件和状态分支迁移，并通过独立 Unity 节点验证；本地商店新标记服务和完整红点图尚未接线。
- 待核实未修复到成熟领取、活动边界、回拨、超容量与小数余量恢复的完整操作，以及不同装潢下的 Windows Player 表现。[幻兽结缘](../functions/pet-gacha.md)单独维护抽取玩法。

## 单机适配实现

一次领取全部成熟果实，原初果实按 1:1 转为命运果实，无额外奖励；小数余量与超容量成熟库存保留。结缘果树的修复差异只在[结缘果树](pet-tree.md)维护。

活动加成和分段结算统一见[离线产出](../functions/offline-income.md)。
