# 小推车

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方小推车窗口管理多项挂机资源，显示各产出项的解锁、等级、产量、容量与可领取状态，提供批量领取、产出项详情与升级、快速领取开关。所选官方中文表未提供该家具的物品描述，不补写替代文案。

## 完成概要

已接入资源行、解锁、升级、容量显示、批量领取和场景收益提示。窗口与资源行仍由提取布局和局部事件绑定控制，当前说明含手写文案，完整原生窗口、详情与升级演出尚未完成。

多产出项解锁、升级、领取刷新及冷读恢复，仍须完成模拟输入、实际画面与 Windows Player 验证。

官方家具表中小推车为无解锁条件、无修复成本的默认家具；离线规则已统一按默认家具处理。独立 Unity 工程宿主验收已实际从主城导航到小推车，点击打开原生 `FurnitureCartDialog`，渲染木车预览、产出行、解锁按钮和一键领取入口。批量领取到账、升级材料消耗及 Windows Player 验证仍待完成。

## 单机适配实现

使用本地账本累计、保存产出项解锁与等级，奖励转入本地角色。共用时间累计、容量、加成与领取规则只在[离线产出](../functions/offline-income.md)维护。
