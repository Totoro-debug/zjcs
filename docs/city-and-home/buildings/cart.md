# 小推车

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方小推车窗口管理多项挂机资源，显示各产出项的解锁、等级、产量、容量与可领取状态，提供批量领取、产出项详情与升级、快速领取开关。所选官方中文表未提供该家具的物品描述，不补写替代文案。

## 完成概要

已接入官方 `FurnitureCartDialog`、产出滚动区、资源行、解锁、升级、容量显示和一键领取入口。刷新只重建官方挂机资源行，保留标题、产出加成、底部按钮及其原生层级；通知层不再遮挡建筑窗口操作。

独立 Unity 工程宿主已从主城实际场景点击小推车，打开官方窗口，点击原始解锁按钮，推进本地挂机时间后点击原始一键领取按钮，并确认已解锁产出被本地账本扣减；窗口返回关闭也已验证。默认家具识别、场景点击、窗口显示、解锁和一键领取标记为完成。

官方家具表中小推车为无解锁条件、无修复成本的默认家具；离线规则已统一按默认家具处理。产出详情、升级材料扣除与升级演出、快速领取开关以及 Windows Player 验证仍待完成。

## 单机适配实现

使用本地账本累计、保存产出项解锁与等级，奖励转入本地角色。共用时间累计、容量、加成与领取规则只在[离线产出](../functions/offline-income.md)维护。
