# 床

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“普通而温馨的床，一觉醒来可以收获许多资源。”

床提供经验挂机、领取、免费与道具快速挂机，以及产量、容量、赐福等级和加成来源预览。场景提示随可领取经验和人物升级需求变化。

## 完成概要

已接入原生床窗口、产量与容量预览、普通领取、快速挂机进度和奖励展示，以及本地经验与属性投影。共用修复、场景提示和收益链路已有实现。

普通领取已核实原生按钮、单次回执、经验到账、奖励展示和存档重开；活动加成详情已核实原生入口、来源分组、倒计时、滚动、关闭、到期过滤及存档重开。免费快速挂机已核实原生按钮、每日次数、睡眠动画自然结束、HUD 恢复和结束后经验到账；道具快速挂机已核实原生数量控件、收益预览、超容量确认、道具扣除、自然动画结束和存档重开，产物留在设施内等待领取。以上功能的 Windows Player 验证与发布尚未完成。活动分段结算、完整升级反馈、中断恢复、音频和 Windows Player 的完整操作仍待验证，建筑未完成。

## 单机适配实现

经验由本地收益账本结算并转入角色；展示奖励不重复发放。快速挂机、加成与时间结晶的已确认方案统一见[离线产出](../functions/offline-income.md)，修复与装潢见[建筑管理](management.md)。
