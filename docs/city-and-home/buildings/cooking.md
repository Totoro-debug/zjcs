# 炼金炉料理

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“既能分解熔化装备，也能……烹饪食材的万能好锅。”

在家园炼金炉查看、学习配方并制作料理。通用物品合成与分解见[行囊](../../character/inventory.md)，宝石合成见[机械师熔炉](gem-forge.md)。物品说明提及的功能不能直接视为已接通的炼金炉操作。

## 完成概要

- 已接入配方条件与排序、配方学习、材料与产物预览、数量调整和批量制作。料理使用服务已连接库存与角色效果保存。
- 列表和滚动仍通过局部控制还原，部分说明仍显示效果编号。界面载荷的读取也仍要求固定来源标识。
- 待核实制作、行囊食用、同种效果刷新和冷读恢复的连贯流程，以及完整界面、动画、音频和 Windows Player 表现。

## 单机适配实现

制作只按已核实的原配方费用与产出执行，不推演服务器额外奖励。连续食用同种料理刷新效果为用户补证的单机规则；料理使用与库存变化须共同保存。

缺少原界面或滚动组件时继续恢复，现有局部适配不构成重新设计界面的许可。
