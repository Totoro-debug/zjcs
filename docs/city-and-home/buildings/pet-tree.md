# 命运之树·结缘

[主城与建筑索引](../city-and-home.md) · [总索引](../../README.md)

状态：部分完成

## 原始功能描述

官方说明：“挂满结缘绳的命运之树，联结与幻兽之间的羁绊之缘。”

结缘果树修复后开放幻兽结缘，包含独立修复资格和解锁剧情。官方配置还关联生产果树的追加修复，单机差异见下文。

抽取控件、每日计数和积分馈赠的原生组件范围统一见[幻兽结缘](../functions/pet-gacha.md)；完整结缘面板尚未完成。

**默认结缘树修复演出：完成当前验证范围。** 独立源码 Unity 主城逐帧核对原生按钮提交后的特效启动、模型按原始显露时间切换、粒子运行和持续时间结束后的关闭，并检查围挡、显露中与结缘绳显示后的场景相机实际渲染；演出后复验原始剧情、提示刷新和冷重开，确认只修复结缘自身。通知语义复用[共用建筑宿主](management.md)。其他装潢的修复演出仍待验证。
