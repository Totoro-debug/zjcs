## 功能简介

维护人物属性、成长、装备、技能、幻兽装配和衣柜；专项规则分别由对应功能页维护。

## 自定义实现

- 所有属性来源、战力和显示共用官方计算规则，变化须同步人物、比较、详情及实战，不另算一套展示数值。
- 用户补证：普通经验超过当季基础上限后继续提升显示等级，超出部分为当季赐福，赛末回到当季基础上限并保留赛季记录。
- 限时装扮重复获得时，允许叠加的按配置时长累加并限制在最大剩余有效期；不允许叠加的按配置重设时长。到期卸下仍沿官方规则。
- 新宝具初始化为有效、未入槽、零星，初始命中数按官方效果类型；装备图鉴在本季穿戴和卸下时同步评分快照。
- 同一幻兽实例允许存在于多个技能方案，人物随行与方案装配分别管理。
- 角色表现采用[免费原生动画方案](character-creation.md#spine-迁移决策)，不以近似表现代替未恢复内容。
- `pWeapon_100_G_125`、`pWeapon_200_G_125`、`pWeapon_100_G_140`、`pWeapon_200_G_140` 的官方高、低精度纹理均为纯白占位。用户确认暂不开放这四个外观，保留原始资源及美术缺口；取得并核实真实官方素材后再恢复开放。主城武器架沿用同一限制。
