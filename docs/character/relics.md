## 完成概要

**培养配置目录与查询：完成当前模块范围。** 已迁移官方古遗物、套装、升级与升星材料、祝福、随机兑换及相关全局配置。保留表与字典的原始枚举顺序、套装属性配对、初始命中数和普通升星上限；赛季属性查询沿用负赛季归零、缺项记录错误并取首项的官方分支。

独立源码 Unity 已验证完整配置查询，并运行所选官方原始方法对照赛季回退、初始状态和套装属性配对。来源、解码输入及运行载荷由[来源清单](../../assets/reference/treasure-rules-source-manifest.json)核验；来源标记不控制运行加载。

**合成与升星费用查询：完成当前模块范围。** 共用查询沿用官方合成材料、累计碎片差额、逐星材料累加及特殊升星碎片差额。保留材料枚举顺序、目标星级上限和缺失特殊档位的分支；独立源码 Unity 使用官方原始方法核对全部古遗物的升星区间及边界。这些查询供培养功能复用，不负责扣除背包或修改存档。

**激活、合成与升星资格校验：完成当前模块范围。** 已直接迁移官方错误码、检查优先级、碎片可合成提示、下一级材料选择、通用碎片换算和培养材料分类，保留材料字典的枚举顺序及原地过滤行为。共用校验通过显式玩家和配置接口读取本地存档，查询不扣费或修改状态；自动合成费用复用[通用材料合成查询](inventory.md#通用材料合成查询)。

独立源码 Unity 已将完整目录各星级、持有与激活状态、材料不足及充足、通用材料开关和自动合成调用边界与官方原始方法逐项对照，并验证隔离存档重开、提交后重新读取及返回对象隔离。实际隔离存档已验证仅持有底层材料时的自动合成升星资格、关闭自动合成时的材料不足结果及费用展开，查询不修改库存。来源及版本兼容依据见[培养来源](../../assets/reference/treasure-cultivation-checks-source-manifest.json)。

**单件激活、合成与升星事务：完成当前模块范围。** 沿官方请求的下一级材料选择、资格校验和回调状态变化执行实际扣费。已持有的零星古遗物激活不额外收费；碎片合成生成本体并直接激活。普通升星与觉醒均递增一星，保留限定碎片、通用材料及自动合成费用分支，不改写命中数和槽位等级。官方激活、升星及刷新通知的顺序和参数已直接迁移。

独立源码 Unity 已对照完整目录的官方状态迁移，并用真实隔离角色存档运行各品质、限定材料和初始命中类别的合成、激活、逐星升级、最高星级拒绝及底层材料自动合成扣费。库存守恒、冷重开、重复请求、其他服务最新提交的保留、真实文件写入失败回滚及恢复后重试均通过。

槽位等级与赐福、批量培养、任务、收藏属性完整生效、原生面板与专属动画尚未完成验证，工作台的正式功能入口仍待接通，不能据此标记建筑完成。

## 自定义实现

培养网络请求改为同一份本地角色存档事务，材料扣除、古遗物参数和请求凭据同笔提交；保存成功后按官方顺序发布培养通知。失败与重复请求不发布成功通知。共用费用及状态迁移模块供后续原生面板和批量操作接入，不另建培养库存。
