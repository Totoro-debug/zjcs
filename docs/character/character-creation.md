# 新建存档与角色创建

[总索引](../README.md)

状态：未完成

## 功能简介

从本地槽位进入开场、角色外观与命名、初始武器选择；保留官方交互和竖屏表现。

## 自定义实现

- 每槽独立保存创建草稿；保存失败阻止继续，损坏草稿保留原文件，不覆盖正式角色。
- 随机名字依赖缺失的服务端规则，按用户确认隐藏随机名按钮，由玩家手动命名。输入沿用官方字符及长度校验。
- 新角色按确认的初心者位阶初始化，初始体力为 300。选择原剑或法杖后继续本地流程。不为旧角色补改初始位阶。
- 开场对白逐句点击推进；未创角槽位的观看标记只在进程内保留，重启后重新播放，不增加“看过一次永久跳过”规则。
- 开场技能特效找不到指定的骨骼挂点时，按挂接配置在对应单位的根节点定位和跟随。
- 缺少遮罩的 `ethnicity_06`、`ethnicity_07`、`ethnicity_22` 至 `ethnicity_27` 选项按用户确认保留，沿官方空遮罩行为不染色，不生成替代遮罩。
- 创角预览以材质参数指定直通 Alpha 贴图，混合前按 Alpha 预乘颜色，避免 Windows 构建裁剪着色器变体后透明区域叠色。
- 窗口缩放保持官方画布比例及控件关系；过渡结束后将输入焦点交给命名框。离线命名隐藏覆盖输入框的预创角提示按钮，允许失焦后点击继续输入。
- 角色创建界面打开时按草稿准备男女两套预览。体型切换复用已载入的网格，从首帧播放待机动作，并执行原选择过渡。

### Spine 迁移决策

采用已确认的免费原生动画迁移方案，复用官方贴图、骨骼、网格、权重、附件和动画数据，保持原表现及执行顺序。

不以购买 runtime 为前置条件，不复制或反编译旧 npm runtime 构造替代实现；未恢复的动画分支继续迁移并实际验证，不能以近似动作当作完成。

开场地面溶解的 Windows shader 适配方案仍待确认。
