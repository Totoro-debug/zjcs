## 自定义实现

- 使用、奖励、随机和计数同笔保存；取消不消耗资源或推进随机。无效或停用的专用物品不转换、不补偿，赛季宝石不补造回收奖励。
- 用户已确认缺图的物品保留原名称、数量及品质框，沿官方缺图文字行为显示，不制作或借用替代图片。
- 特殊物品按原资格、费用和词条规则处理，工具包重置保留既有产量及解锁；砥石逐份保留期限，优先使用或分解最早到期份。
- 联动资格需要开服时间时以本地存档创建时间对应；史莱姆与孤独摇滚仍按[暂停范围](../common/offline-access.md#暂不开放的联动活动及伙伴)处理。
