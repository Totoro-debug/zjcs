## 自定义实现

自由转职生成三组方案后取消不消耗转职石，最终确认才扣：免费方案零个、非免费一个。免费间隔沿原 168 小时，生成免费方案时推进，放弃不重置；费用、方案、职业和奖励同笔保存。

职业动画沿[免费原生迁移方案](character-creation.md#spine-迁移决策)。
