## 实现要点

按官方描述迁移主动战技、被动秘法、被动与触发效果、子技能、增益与减益、动画及人物动作；已确认的单机边界只在对应技能的实现要点中简述。

合成、装配、升级、进阶与存档使用公共培养及界面流程，技能差异由官方配置驱动。

装配仅使用已持有且职业可用的技能；空战技方案允许进入战斗，正常结算回合与被动，不自动补战技。

连锁攻击遵循已确认的[单机目标选择规则](../combat/battle-execution.md#自定义实现)。

共享战斗模块负责读取数值配置、展开命中图、计算伤害、处理状态与触发，以及播放原生技能图。四阶配置校验覆盖职业绑定、实体引用和主动战技的演出绑定。战斗冒烟测试覆盖主动及内置战技的选取和施放。具体效果和动画仍需逐项验证。

五阶及以上职业仅保留既有技能说明，不计入本次完成范围。

四阶技能须逐项验证描述、数值、全部适用效果及分支、原生演出、存档恢复和 Windows Player 中的受影响流程，全部通过后标为已完成。

Windows 技能流程可在同一验证进程中顺序执行；每个技能使用独立测试存档并保留各自的战斗结果，全部通过后才记录整组成功。
