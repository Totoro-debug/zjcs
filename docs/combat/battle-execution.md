# 战斗执行

[总索引](../README.md)

状态：未完成

## 功能简介

所有剧情、地图和玩法战斗共用官方规则、原生演出、战报及可恢复检查点；专属奖励与退出结算归对应玩法。

格心和指针投影以地形所在的局部坐标系为准。战场读取兼容数组和对象格式的原点，恢复战斗时从对应场景校正原点，保留检查点中的逻辑格坐标。技能测试和各玩法的战斗入口将当前入场格锚定到玩家位置。开场剧情的旧地形导出使用不同的格心偏移，接入共同投影前由开场场景转换。

## 完整还原部分

恐惧沿官方词条降低状态施加者的攻击目标优先级；有其他可攻击目标时优先其他目标，只有施加者可攻击时仍可攻击。公共选敌和移动选点共用此规则，状态禁用、移除或到期后恢复正常选敌，原有强制选敌继续生效。

受击状态监听默认匹配实际受击者，明确配置攻击者匹配时沿其来源规则筛选。禁用或没有层数的监听不触发；闪避、致盲和免疫不作为有效受伤触发，护盾完全吸收的有效命中仍可触发。各技能继续使用原配置的次数、叠层、培养属性和持续时间。

纯属性秘法的新增迁移按技能保存官方培养分组、等级属性和默认值，角色属性、详情与战斗使用同一计算入口。共享原分组编号的既有技能保留原来源。默认值只补缺少的属性，显式零值保留；重复来源或技能参数不一致时拒绝装配。

原生技能图与实体加载共用来源校验，分别验证载荷哈希及来源一致性；新迁移只替换声明的技能、命中、位移和伤害实体，拒绝重复来源与迁移间的覆盖冲突，不以固定来源版本决定加载。状态图仅允许按实体编号及前后目录明确声明的迁移替换，其它重复注册继续报错。各技能的实际规则和运行验证仍归所属职业页。

技能召唤实体共用完整骨骼、动画控制器、材质、挂点、阴影及生成／死亡演出的转换与加载流程，各实体分别保留官方层级、资源绑定和来源一致性。骨骼动作按已核实的模型来源及原始动画对象检查身份，保留结构、约束和有限数值检查。固定属性、主人继承比例、品质系数及等级曲线共用当前官方配置核对；具体技能的运行范围和完成状态归所属职业页。召唤数量监听在通用属性刷新中同步，入场和最后一只离场均在本次结算更新增益，并保留对应原生状态事件。模型释放前通过原生跟随器的清理接口解除附着特效绑定，避免残留特效继续访问已销毁的骨骼。

用户统一约定：技能的比例项与固定项均须生效，基础伤害按“固定伤害＋倍率×基础属性”求和，再进入公共精通、会心、亲和、伤害或治疗加成、抵抗等后续链路；角色和宠物的战技减伤同样作用于求和后的整体。条件组件中的成对固定值不能因只指定百分比属性而遗漏；同一效果的固定项先于百分比处理，具体触发阶段及其它分支仍沿用官方链路。条件减伤使用状态自身的培养数值，并在满足条件的命中中按层数及来源技能类型缩放；禁用时不生效，也不重复计入常驻属性。

范围状态的人数判断只统计已入场且未离场的单位，同一大体型目标计一次；人数分支产生的自身状态在父状态禁用或移除时一并清理，重新启用后按当前人数重新计算。

角色死亡图及伤害显示目录不以官方来源版本或旧条目数量决定加载，继续检查数据结构、对象引用和唯一标识。当前验证覆盖伤害显示过滤，以及男女战士／法师的普通和开场死亡、暂停释放、强制重播与复活参数恢复；已核对实际运行画面，完整换装、过渡帧混合及 Windows Player 仍属独立验证范围。

主题 NPC 的本地文本目录按字段及资源绑定读取，不检查游戏来源版本号；该读取调整已通过 Unity 编译，主题 NPC 画面不在本次运行验证范围。

移动特效、移动动画、怪物动画控制器、怪物状态绑定及演出相机目录按实际结构和对象引用读取，不携带加载用的来源版本字段。项目校验及静音 Play Mode 的 11 个公共战斗场景已通过，覆盖模拟开战、移动、暂停、施法、受击、技能消耗、吸血、状态动作及不同角色模型，并核对实际画面；本项未新增 Windows Player 验证。

## 自定义实现

以下保留无法从官方客户端查回的单机裁决，不代表已完整实现或通过运行验证。

### 行动、选敌与移动

- 开战前战技先结算开场被动，再按速度、技能槽顺序尝试；同速按编队顺序。无视初始冷却尝试一次，成功正常计次和进冷却，条件或目标不满足不消耗。“初始冷却完成”的技能首回合可释放。
- 普通行动先移动再放技能，无可释放技能时原地不退避。普通移动在行动力的欧氏距离圆内选合法完整身体落点，中途不按四向步数寻路，沿原小跳表现；特殊位移沿原配置。
- 跳劈直接跳到范围内可站立的目标空地，途中单位和阻挡不影响落点。
- 大型目标任一身体格在范围内即可选中，接近位置也按身体格寻找；不扩展施法者自身范围。多格攻击逐格独立命中，大怪多格覆盖可多次受伤，但技能只放一次，保留原衰减、随机及明确限制。
- 对敌攻击／减益互斥选敌优先级：优先标记敌人、覆盖最多的大怪身体格、可同时命中至少两名敌人的落点；否则最后一个战技优先安全，其他优先少移动，再按敌方生命百分比。有效分支同分优先远离敌方整体，无合法施法位置则尽力接近；治疗与增益沿自身目标规则。安全性依次比较最近敌格距离、至各敌最近身体格距离之和。
- 命中范围沿技能释放时的方向、翻转与原中心变换；随机抽中的实际身体格保留，不改回单位中心，空格选择也保留，多次抽中同一实体不同格仍为独立命中。
- 连锁首跳从技能施法位置开始，后续从上次实际命中格开始；禁止重复时排除已命中目标，禁止返回时排除上一目标，优先未访问后按距离与实体标识排序，无候选停止。同一起始命中的分叉共享访问集合，不同随机起点独立；下一跳平移原技能范围搜索，实际伤害仍用原命中范围。
- 子命中与命中监听触发的子技能均从父命中实际触发时刻起等待各自延迟；连锁在上一跳伤害触发后等待子引用延迟再创建，自身飞行和范围延迟继续保留。由命中触发并使用自身位置的子技能从实际命中格开始，继承该命中方向／翻转，施法者身份与真实位置独立。

### 受击位移与召唤

- 受击位移从触发它的命中时刻起按原配置延迟执行。
- 负一距离的靠近配置以原来源或选定目标加偏移为参考；非零偏移须到参考点，零偏移取最近可站且比起点更近的位置。完整身体和阻挡继续检查，缺少参考目标不猜测；不支持的远离配置不移动。
- 已确认的前方范围直线击退沿释放时四向朝向，受阻缩短；目标相对位移以选定目标为参考，重合或缺目标不动，风压护盾则以持盾者向外推。
- 崩山斜向击退时，目标格可站立即直达，两侧相邻格的单位和障碍不影响；目标格受阻时按击退碰撞规则处理。
- 路径两侧位移以施法者至选定目标连线为中心；横向距离不小于纵向时上下侧移，否则左右侧移。中心线上先正轴、受阻再负轴，线外只缩短已选方向，靠近不得更远，无方向不推测。
- 狂热图腾靠近既选友方，灵铠与汐卫靠近敌方；在原范围内按距目标身体的曼哈顿距离、距施法者身体距离、原范围顺序选一合法格。无合法范围格才尝试自身格，只忽略施法者自身占用，其余合法性、概率和数量限制保留。父节点不伤害、不抽随机，回退格不增加逐格延迟。

### 状态、伤害与统计

- 用户确认的单机来源规则：不同施法实体或同一实体不同技能施加的同种状态独立存在、分别结算；同实体同技能刷新最早的合格旧实例，采用最新来源与培养，保留实例、护盾余量、已有属性效果、调用次数和条件累计。叠层与追加持续时间仍按官方配置处理，否则刷新为原配置持续回合；同场战斗同一实体同一技能的培养保持一致。
- 已施加的来源型效果在施法者死亡或离场后，继续使用战斗中保留的来源记录结算；没有来源记录时不补造施法者，也不放宽目标的存活条件。
- 用户确认的燃烧实体计数：以状态持有者当前位置统计范围内未移除的燃烧实体，不区分归属，先按配置封顶再加偏移；治疗倍率只对当前命中临时合入，单纯属性修正不受子技能开关限制。
- 伤害在命中或碰撞动画到达目标时结算，同步生命变化、受击事件和伤害数字；增益与减益表现随实际状态变化播放，暂停时不提前结算。
- 公共生命结算将治疗后的生命值限制在最大生命以内，即使原生命值与治疗量之和超出整数范围。回执分别保留原始治疗量和实际恢复量。施疗方或受疗方的治疗评级基数缺失或为零时，跳过该项评级加成，基础疗量、直接百分比和其他有效加成照常结算。
- 状态改变最大生命时，按变更前的生命比例计算当前生命，存在小数时向上取整，结果受新的最大生命限制。
- 次数护盾若未配置扣减剩余盾值，每次仍按原有吸收额度结算，直到用完次数。护盾实际吸收量超过回执的整数上限时，回执取上限，剩余伤害仍按实际吸收量结算。
- 未另定规则的唯一效果由新效果替换并刷新。虚空祝祷按实际最大生命加成取较强者，同强换新来源并刷新，弱效果不刷新也不在强效果结束后恢复；所有目标使用施法开始的同一来源属性快照，额外治疗只在生命严格低于 30% 时触发。
- 基础吸血以本命中实际扣除生命为基数，排除护盾、溢出及后续共享／复活；乘配置比例后向零截断，不另封顶，正数经原统一治疗链处理。满血仍有治疗演出，统计只记实际恢复，独立技能吸收规则不套用本项。
- 仅实际驱散时通知一次，同刻先受伤再驱散；无状态、概率失败或自然到期不通知。免疫保护的正次数只按实际拒绝消耗，非正数不限，达限按原销毁标记移除。
- 伤害元素取实际施放技能元素，包含状态改写；本次伤害直接状态列表至少成功施加或续期一次才播放状态触发特效，其他被动连带状态不计。
- 伤害实体位置冻结于本次结算及位移前：范围命中用实际身体格，点命中用当时目标位置，方向／翻转沿施法快照，不追随后续位置。
- 伤害、治疗与未执行两者分别分类，零伤害或免疫仍属伤害；无伤害／治疗的命中保留实际状态、驱散、位移和子技能，不凭生命正负猜分类或增加伤害次数。
- 伤害、护盾、增益、减益分别统计，增减益都计人物施加状态；只记成功添加或续期，恢复不重计，纯护盾不改成增减益。
- 标为非独立倍率的同类增减伤先合并再应用一次，扣盾前处理，保留原条件过滤；共享状态首次施加只分配剩余额度，额度不足部分分配、为零不创建，结束释放占用。
- 状态蓝图同一次事件共用临时黑板、事件结束丢弃；持久端口按所属状态保存恢复，两类同标识不串读，触发技能先捕获倍率再结束事件。
- 幻兽主动支援在主人回合开始且原回合监听后、普通技能前检查，符合原条件额外释放，不占普通行动，支援次数及冷却独立。
- 普通命中与替身传导致死共用死亡响应、即时复活和召唤物移除链路，按原命中时序执行；生命阈值效果和上述响应完成后仍为零生命，才确认死亡、禁用相关状态并播放死亡表现。同次即时复活不禁用，恢复正生命后解除并播放复活表现。召唤物自然消失单独派发移除响应，回执恢复不重复触发。
- 状态 26030 的服务器属性倍率单机固定为 1，不附加缩放，准备阶段保留待计算说明，开始后显示无衰减。

### 表现与恢复

- 同场冒险者按各自单位的外观档案绑定原生角色模型，共用模型、换装及技能演出模块。
- 开场和其他战斗共用血条规则。首领级怪物只显示顶部大血条，左侧使用对应首领的头像。单位状态图标保留。行动动画期间显示本次行动时间，切换后再显示下次时间。
- 普通存档按普通位面处理，不无条件触发洛天依主题；原类型筛选与概率仍有效。
- 逻辑已结束而演出交接未完成的检查点，恢复后首个未暂停更新先交战报再交完成，不重复规则步骤。普通战斗仍等待最后演出结束。
- 日常副本、混沌中退正常部分结算，竞技场主动退出判负；细则分别见[副本](../travel-notes/dungeons.md)、[每周挑战](../travel-notes/weekly-challenges.md)。幻想阶梯隐藏时仍执行真实后台规则，不向停用模型发送新演出，返回按当前检查点刷新。
- 按全新游戏制作，不新增旧存档兼容规则。重放已结算的步骤只读取回执并返回独立的事件副本。继续战斗的状态及回执应与未中断的战斗一致。部分消耗的护盾恢复后应保留剩余值，下一次受击分别核对护盾吸收量和生命损失。专属地图等级、奖励和回滚归对应页面。
