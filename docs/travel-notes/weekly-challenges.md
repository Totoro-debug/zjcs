# 虚空裂隙与混沌侵袭

[总索引](../README.md)

状态：未完成

## 功能简介

维护虚空裂隙与混沌侵袭；魔王属于混沌战斗阶段。

## 自定义实现

- 每周日 06:00 开放，保留原阶段顺序和时长；混沌累计改为本人本期实际魔王生命伤害，原门槛取十分之一、奖励不变。计入本体、召唤物及幻兽，不生成真人贡献。
- 周期首次入场冻结等级与阶位，沿原世界阶段怪物等级；查看或领取旧期不补造历史。无原 NPC 邀请配置时不添加助战。
- 目标按已确认的合法地图点本地生成，每五秒维护并保存批次与截止时间；保底长期保存不按周清空，层间计时按本地持续推进。
- 混沌商店在本期结算开始时开放 24 小时。
- 中途退出正常结算已造成伤害，不伪造胜利或击杀；魔王每期首次结算即领取挑战奖励，零伤害退出也消耗资格，跨期恢复仍结算入场期，重复请求不重复发奖。
- 回合耗尽沿原回合限制提示，不冒充真实时间耗尽。刷新与时区见[06:00 约定](../city-and-home/city-and-home.md#全模块刷新时刻)。
