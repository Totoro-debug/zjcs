# 伙伴旅行、品质与保底

[总索引](../README.md)

状态：未完成

## 功能简介

维护伙伴旅行候选、品质、派遣、召回及收益。

## 自定义实现

- 按当前位置、地域、品质和原权重本地抽样，作为已确认的离线近似，不声称复现服务器随机。首轮用原固定列表，多品质保底同时到期时低品质先行；保底跨每日刷新保留，生成对应品质才重置。
- 本地位置取当前主线地图中已推进的地区；有多个候选时，按原旅行节点顺序取最高已推进位置。
- 每日刷新沿[06:00 约定](../common/refresh-time.md)，未领取旅行保留；同日进入新地区只重抽空闲位置，不重置当天次数或进行中的派遣。
- 派遣时冻结候选、伙伴、属性、奖励及随机快照，途中变化不重算，回拨不提前完成；奖励按原规则本地抽样。
- 召回不发奖并恢复原委托；派遣当日召回退还当日派遣和伙伴次数，跨日召回不改新一天计数。
