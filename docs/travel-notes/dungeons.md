# 游记入口与日常副本

[总索引](../README.md)

状态：未完成

## 功能简介

游记汇集日常副本、竞技场及各类挑战；各玩法共享本地战斗与存档。

## 自定义实现

- 日常副本仅成功领取最终奖励时扣领奖次数，进场、失败和未领奖不扣；跨日总余额取前日剩余与每日免费次数较大值，购买档位及记录每日重置。批量领奖只增加已有有效福利允许的次数。
- 保留选路倒计时，玩家可立即手动前进；超时按原房间优先级及配置顺序选择，不模拟在线投票或缺失的队伍决策。
- 排行只用评级降序和通关时长升序，完全并列保留原顺序；首通队伍独立保存，不用后来最佳队伍或缺失记录回填。排行榜馈赠按本档指定难度及评级的真实累计通关数判断。
- 日常副本中途退出正常结算：按已清理房间计算评级及掉落，当前未清房间不补算；达标后正常领奖扣次，未达评级仅发房间掉落。未到终点不增加完整通关或排行。
- 竞技场以本地守卫和个人名次代替在线玩家；主动退出判负，已扣挑战票不退、不重复扣，清除本场可续挑战。战斗中取消退出则继续当前战斗。
- 保留既有“正常挑战／直接胜利”选择，但不以此替代完整官方备战页。旧奖励仅有已入库标记而缺明细时继续去重，不重抽或猜测历史物品。
- 公共物品的完整使用、合成和来源交互另行迁移；海之宫静态地块沿[技能规则](../character/skills.md)处理。
